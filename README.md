## Project Objectives
- An ability to use SPI to communicate with a TFT LCD and display text from digital books.
- An ability to use SPI to read text and MP3 audio files from a MicroSD card.
- An ability to use PWM to control a NeoPixel LED strip that indicates reading progress and audio playback progress.
- An ability to use PIO to generate audio output from decoded MP3 files and play the audio through a speaker.
